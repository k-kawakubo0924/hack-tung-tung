🌸 Sakura Up（サくらアップ）
「今、どこでサクラが咲いている？」を解決する、お花見ルート探索・共有アプリ。

📝 概要
Sakura Up は、OpenStreetMap（OSM）の膨大なオープンデータを活用し、街中に隠れた桜の木を一本単位で見つけることができる地図アプリケーションです。ハッカソンのテーマ「さん（散・山・燦）」に基づき、春の街を散策し、燦々と輝く桜を楽しむための体験を提供します。

✨ 主な機能
サクラ・マッピング: Overpass API を使用し、現在地周辺の桜の木（natural=tree, species=Prunus）を地図上にリアルタイム表示。

スマート・クラスタリング: react-leaflet-cluster を採用し、密集した桜を数字でまとめ、地図の視認性と動作パフォーマンスを両立。

オート・ロケーション・ネーミング: ピンを立てた位置の住所や施設名を Nominatim API で自動取得（逆ジオコーディング）。

現在地追跡: ブラウザの Geolocation API と連携し、ワンタップで現在地周辺の桜スポットへジャンプ。

🛠 技術スタック
フロントエンド
React (v18): コンポーネント指向による UI 構築

TypeScript: 型安全な開発と保守性の向上

Tailwind CSS: ユーティリティファーストなスタイリング

地図・位置情報基盤
Leaflet / React Leaflet: 地図描画・操作エンジン

react-leaflet-cluster: マーカークラスタリングの実装

OpenStreetMap: 地図データソース

Overpass API: 桜の木に特化した空間クエリ検索

Nominatim API: 座標から場所名への変換

🚀 こだわりのポイント
負荷軽減の設計（Debounce）: 地図の移動ごとに API を叩くのではなく、移動停止から一定時間（3秒）待機してからリクエストを送るデバウンス処理を実装し、サーバー負荷と通信量を最適化しました。

UXの追求: ユーザーが投稿する際、住所を入力する手間を省くために自動地名取得機能を搭載。博多や長崎といった地域名が即座に反映されるスムーズな操作感を実現しています。

📈 今後の展望（Roadmap）
お花見ルート・ナビゲーション: Leaflet Routing Machine を活用し、現在地から複数の桜スポットを巡る「歩行・自転車・車」別の最適ルート生成機能。

サクラ・ヒートマップ: 桜の密集度や開花状況を色の濃淡で表示。

プッシュ通知: お気に入り登録した場所が「満開」になった際のアラート機能。
